## 已解释与尚未解释

已解释：在同一组输入、所有引擎参数、训练样本、收入估计表及完整成本过滤结果都相同的前提下，仅解除已有持仓的加仓等待，估值年化增加 **1.9226 个百分点**；平均成本口径占用从约 147.7 万升至 236.6 万 U，小时末回撤从初始本金的 1.1720% 升至 3.5126%。

尚未解释：v1 到 v2 的费率门槛、信号来源、持仓容量风控、预算、时点、库存输入、成本及期末处理对全部收益差额各有多少贡献。未完成这些因素的同数据逐项复跑，不能把全部差距归因于加仓、1h 合约、滑点或某一处修复。

更符合明确规则的是：保留已知信息时点，空仓首笔等复查，已有持仓满足条件可加仓。执行准确性仍需额外证据；本次没有调整成本参数来追求某个年化数字。用于加仓的收入估计表仍来自复查时点样本，其周期内适用性尚未单独标定。


## 2026-11-06 复核更正

先前把 v1 退出依据写成持仓净资金费，是依据 README 作出的错误对照。实际运行参数 `x_obs=1`，引擎使用市场原始 24h 合计；上表已更正。v1 默认存在的前一小时预算逻辑也会被头条调用覆盖，必须核对有效参数，不能只看默认值。

当前 v2.1 的同数据诊断中，只恢复 v1 的持仓容量减仓 `derisk=1`，年化由 21.7481% 变为 31.9920%，期末完全退出；仅将未标定的自身资金费冲击 k=4 改为 k=0，持仓路径完全相同，估值年化变为 55.8097%。后者只是参数敏感性，v1 本身也有 k=4，不能冒充原版复现或推荐值。

这些实验证明规则与参数设定会显著影响结果，不能用收益较低证明 v2 更可靠。尚未取得原 52.76% 对应的完整匹配输入，未完成原收益的严格复现。本轮只修正文档事实，当前交易代码和主线结果保持不变。
